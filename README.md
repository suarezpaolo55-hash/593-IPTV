# 593-IPTV 🇪🇨
App de canales públicos y gratuitos de Ecuador para Android.

## ✅ ¿Qué hace esta app?
- Muestra una lista de canales ecuatorianos que transmiten gratis por internet
- Al tocar un canal, reproduce el video directamente
- Solo contenido legal y de acceso público

## ⚠️ Importante
Esta aplicación SOLO usa enlaces oficiales y públicos de cada canal. No incluye contenido de pago ni enlaces no autorizados.
